# Stripe в тестовом режиме

Подписки Artist и Artist Pro оплачиваются в Stripe. Для слушателей отдельная подписка пока не реализована. Проверяйте платежи только в test mode, не отправляйте секреты и файл `.env` в чат и не добавляйте их в Git.

## Настройка

1. В тестовом кабинете Stripe создайте повторяющиеся цены для Artist и Artist Pro (в месяц и, при необходимости, в год). Скопируйте именно ID цены `price_...`, не ID товара `prod_...`.
2. В существующем `.env` укажите `APP_URL` и `CLIENT_URL` с адресом сайта (например, `http://127.0.0.1:8000`), тестовый `STRIPE_SECRET=sk_test_...`, значения `STRIPE_ARTIST_MONTHLY_PRICE_ID`, `STRIPE_ARTIST_ANNUAL_PRICE_ID`, `STRIPE_ARTIST_PRO_MONTHLY_PRICE_ID`, `STRIPE_ARTIST_PRO_ANNUAL_PRICE_ID`, и при необходимости `STRIPE_CURRENCY=USD`. Фиксированные суммы в `config/plans.php` должны совпадать с ценами в Stripe: 2,99/35,88 USD для Artist и 6,99/83,88 USD для Pro. Интерфейс не сверяет их автоматически.
3. Установите Stripe CLI по официальной инструкции: https://docs.stripe.com/stripe-cli/install и войдите командой `stripe login`. В отдельном окне выполните:

   ```powershell
   stripe listen --forward-to http://127.0.0.1:8000/api/v1/billing/webhook
   ```

   Возьмите выданный CLI секрет подписи `whsec_...` и укажите его в `.env` как `STRIPE_WEBHOOK_SECRET`. Не закрывайте CLI во время тестирования webhook. Секрет для CLI может отличаться от секрета настроенного в Dashboard endpoint.
4. В каталоге проекта выполните `php artisan migrate`, `php artisan optimize:clear` и `npm run build`; запустите приложение. Не используйте `migrate:fresh` или `--seed`, чтобы не потерять и не дублировать данные.
5. Войдите в тот же аккаунт Homeostat. Если оплата уже совершена, откройте «Подписка» и нажмите «Проверить оплату в Stripe». Не покупайте второй раз. Должен отобразиться подтверждённый тариф. Для новой оплаты используйте тестовые карты Stripe: https://docs.stripe.com/testing. Кнопка «Отменить подписку сейчас» отменяет подписку немедленно без автоматического возврата денег и возвращает бесплатные ограничения. Для изменения тарифа используйте управление оплатой; клиентский портал должен быть настроен в Stripe test mode.

Проверка ищет совпадающую оплаченную активную сессию в последних 300 сессиях того Stripe-аккаунта, чьи ключи указаны в `.env`, и только для текущего пользователя Homeostat. Цена должна совпадать с одним из указанных Price ID. При нескольких разных активных подписках требуется проверить их в Stripe: приложение не отменяет лишние автоматически. Webhook нужен для обновления при последующих изменениях платежей и отменах; если он недоступен, нажмите «Проверить оплату» повторно.

## Что доступно сейчас

- Free: 180 минут суммарно, один закреплённый опубликованный трек.
- Artist: 180 минут суммарно, пять закреплённых треков, два включения буста за календарный месяц, отключение комментариев.
- Artist Pro: безлимит общей длительности загрузок и бустов, пять закреплённых треков, отключение комментариев, значок PRO.

Кнопки находятся на странице собственного трека. Буст поднимает трек в начале каталога при сортировке по умолчанию и остаётся включённым до ручного выключения; повторное включение расходует ещё один доступный буст. При окончании платного тарифа буст не влияет на сортировку. Длительность загружаемых файлов и размер одного файла по-прежнему проверяются отдельно.

Замена аудио, мастеринг, расширенная статистика, донаты, отложенная публикация, цвет волны, разделение выплат и тарифы слушателя пока не реализованы. Не считайте их доступными после оплаты.
