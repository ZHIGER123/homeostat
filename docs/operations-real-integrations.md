# Реальные интеграции Homeostat

## Email-код

- `POST /api/v1/auth/email/request-code` принимает имя, email, роль и CAPTCHA.
- Код хранится только как хеш, действует 10 минут, имеет максимум 5 попыток и повторно отправляется не чаще одного раза в 60 секунд.
- `POST /api/v1/auth/email/verify-code` одноразово подтверждает код и выдаёт Sanctum-токен. Для уже существующего email вход возможен только после подтверждения доступа к почте.
- Ответ запроса кода не раскрывает, существует ли адрес.
- Для рабочей почты нужно настроить SMTP/API mailer и `MAIL_FROM_ADDRESS`; `MAIL_MAILER=log` в локальном окружении только пишет код в Laravel log и не является доставкой пользователю.

## Google OAuth

Нужны `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` и точный `GOOGLE_REDIRECT_URI`. Redirect URI должен совпадать с URI в Google Cloud Console. Сервер принимает только профиль с корректным email и признаком подтверждённого email; access token не передаётся в URL, а временный exchange-handle одноразовый.

## Прослушивания и загрузка

`POST /tracks/{track}/play` считает только опубликованный трек и не чаще одного раза за 30 секунд на пользователя или IP. Увеличение выполняется атомарно в БД, а API возвращает актуальное значение `plays_count`. UI обновляет число после ответа сервера и показывает прогресс multipart-загрузки.

## Админ-панель

Серверная проверка `auth:sanctum`, `not_blocked` и `role:admin` остаётся обязательной. Панель позволяет прослушать pending-трек, одобрить его или отклонить с обязательной причиной, управлять жанрами и блокировать пользователей. Скрытие раздела во frontend не считается контролем доступа.

## Stripe и Казахстан

Checkout, Billing Portal и webhook используют Stripe API, но рабочее подключение не считается подтверждённым без Stripe-аккаунта, зарегистрированного в поддерживаемой Stripe стране, заданных Price ID и подписанного webhook. До проверки аккаунта пользователя реальные списания не выполняются.

В production нужно задать `STRIPE_SECRET`, `STRIPE_WEBHOOK_SECRET` и Price ID для четырёх тарифных вариантов. Webhook проверяет подпись, временное окно и идемпотентность событий; привилегии берутся только из активной локальной подписки, синхронизированной webhook. Для пользователя из Казахстана необходимо отдельно проверить страну регистрации торгового аккаунта и доступность выбранной валюты/тарифов в Stripe. Если аккаунт Казахстана неприменим, провайдера можно менять только после согласования альтернативы.
