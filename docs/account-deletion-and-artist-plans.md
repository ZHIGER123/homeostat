# Удаление аккаунта и подписки артистов

## API и подтверждение
- DELETE /api/v1/me: Sanctum, незаблокированный владелец; текущий password и confirmation=УДАЛИТЬ обязательны. Неверный пароль/подтверждение — 422, успех — 204.
- DELETE /api/v1/admin/users/{id}: admin; confirmation_id обязан совпадать с ID в URL. Через административный маршрут нельзя удалить себя — используйте профиль с паролем. Последний незаблокированный администратор защищён от удаления (409).
- Удаление необратимо: FK-каскады удаляют собственные треки/плейлисты/взаимодействия/тариф; отдельно удаляются Sanctum-токены, сессии, reset-токены и email-коды. Чужие пользователи, треки и жанры не удаляются. Запрос удаления не принимает подставной user_id для выбора владельца.
- Файлы аудио local/tracks, public/covers и public/avatars удаляются после транзакции БД. При ошибке диска запускается повторная очистка через очередь; ошибки также журналируются. В production нужен работающий worker и мониторинг failed_jobs. Резервные копии и уже скачанные файлы этим действием не уничтожаются.

## Оплата при удалении
Активные и past_due/unpaid Stripe-подписки отменяются до удаления записи аккаунта. При отказе Stripe пользователь, токены и файлы остаются. Автоматического возврата денег нет. Отмена в Stripe необратима даже при последующем сбое БД — повторное удаление сверяет текущее удалённое состояние.

Новая таблица billing_checkout_sessions хранит ссылки Checkout, созданные после обновления. При удалении открытые ссылки закрываются в Stripe; уже завершённые сессии проверяются, связанные подписки отменяются. Ссылки, созданные до внедрения таблицы, не могут быть восстановлены из неё: проверьте такие незавершённые оплаты в Stripe вручную. Поздний webhook не воссоздаёт удалённого пользователя.

## Роль
Только role=artist может оформить Checkout, синхронизировать/активировать платный план, возобновить подписку или открыть платёжный портал. Admin не имеет обхода. Для listener/admin currentPlan всегда free, даже при старой активной записи. Отмена ранее оформленной подписки остаётся доступна. Активного артиста нельзя перевести в listener до отмены подписки. Проверки действуют и в сервисе, и при применении активного webhook, а не только в кнопках.

Слушатель становится артистом после первой успешной загрузки. Просмотр информации о тарифах и бесплатное использование остаются доступны всем. Речь о платных тарифах Artist/Artist Pro, не о подписке слушателя на исполнителя.

## Обновление
```sh
php artisan migrate
php artisan optimize:clear
npm run build
php artisan test --filter=AccountDeletionTest
php artisan test --filter=ArtistSubscriptionAccessTest
php artisan test --filter=BillingSyncTest
php artisan test
```
При использовании npm run dev перезапустите его вместо production-сборки. Для повторных файловых очисток при QUEUE_CONNECTION=database: php artisan queue:work --tries=5. Основная очистка выполняется сразу; worker нужен при ошибках хранилища. Секреты Stripe только в приватном .env.

PHPUnit необходимо запускать на машине с PHP: браузерный mock-стенд не подтверждает транзакции MySQL или реальную отмену оплаты. Конкурентные блокировки нужно дополнительно проверять на MySQL, а не только SQLite.
