# КП10 — тест-кейсы API Homeostat

Матрица предназначена для ручной проверки после запуска Laravel и отдельной тестовой БД. Ожидаемые результаты сопоставлены с маршрутами, Form Request, Policies и Feature-тестами в репозитории.

| № | Сценарий | Запрос / подготовка | Ожидаемый результат | Фактический результат при подготовке отчёта |
|---:|---|---|---|---|

| 2 | Дублирование email и роль admin | `POST /api/v1/register` с занятым email и `role=admin` | 422, русские ошибки валидации | Не запускался: локальный PHP/Composer недоступен |
| 3 | Неверный вход | `POST /api/v1/login` с неверным паролем | 401, безопасное сообщение без деталей | Не запускался: локальный PHP/Composer недоступен |
| 4 | Текущий пользователь и выход | Login → `GET /api/v1/me` → `POST /api/v1/logout` | 200; после выхода токен недействителен | Не запускался: локальный PHP/Composer недоступен |

## Автоматическое покрытие

В ветке уже присутствуют API Feature-тесты с `RefreshDatabase`, фабриками и SQLite-конфигурацией PHPUnit: `AuthApiTest`, `ErrorFormatTest`, `GenreApiTest`, `InteractionApiTest`, `ModerationApiTest`, `PlaylistApiTest`, `TrackApiTest`, `TrackWorkflowTest`. Перед сдачей необходимо выполнить `php artisan test` и перенести фактические числа и статусы в отчёт.
