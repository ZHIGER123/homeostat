# КП11–КП12: чек-лист клиентской части

Клиент реализован внутри Laravel на Blade + Vite + vanilla JavaScript. Все данные, кроме состояния интерфейса, загружаются из REST API `/api/v1`.

## Основные страницы

- `#login`, `#register` — вход и регистрация с выводом ошибок 422.
- `#tracks` — каталог опубликованных треков, поиск, жанр, сортировка и пагинация по 20 записей.
- `#tracks/{id}` — карточка, потоковое аудио, учёт прослушивания, лайк, подписка и комментарии.
- `#upload` — загрузка собственного трека артистом через `multipart/form-data`.
- `#edit/{id}` — редактирование собственного трека с повторным направлением на модерацию.
- `#favorites` — список лайкнутых треков.
- `#feed` — лента опубликованных треков артистов, на которых оформлена подписка.
- `#playlists`, `#playlists/{id}` — создание, переименование, удаление, добавление, удаление и перестановка треков.
- `#profile` — изменение имени, описания и пути к аватару.
- `#stats` — статистика артиста с фильтрами `from` и `to`.
- `#admin` — очередь модерации, жанры и блокировка пользователя по ID.

## Ключевой сценарий

1. Зарегистрироваться с ролью `artist` или войти тестовым артистом.
2. Открыть «Загрузить», выбрать жанр, аудиофайл и отправить форму.
3. Убедиться, что сервер вернул статус `pending`.
4. Войти администратором и открыть «Администрирование».
5. Одобрить или отклонить трек. При отклонении причина обязательна.
6. После одобрения открыть каталог, карточку трека и запустить аудио.
7. Проверить лайк, комментарий, подписку и добавление трека в плейлист.

## Проверка Network

В браузере необходимо проверить:

- `Authorization: Bearer ...` у защищённых запросов;
- `Accept: application/json` у API-запросов;
- `Content-Type: multipart/form-data` для загрузки (заголовок выставляет браузер, включая boundary);
- запрос `OPTIONS` при использовании внешнего origin;
- `Access-Control-Allow-Origin` со значением `CLIENT_URL`;
- отсутствие `*` и отсутствие `Access-Control-Allow-Credentials` для Bearer-режима;
- ответы 401, 403, 409 и 422 в реальных сценариях.

## Важное ограничение

Runtime-проверка зависит от установленного PHP 8.3+, Composer, MySQL 8 и Node.js. После развёртывания выполнить:

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate:fresh --seed
php artisan storage:link
npm install
npm run build
php artisan test
```
