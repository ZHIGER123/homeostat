# КП10 — ручная проверка Postman

Коллекция: `docs/postman/Homeostat.postman_collection.json`.

## Подготовка

```bash
cp .env.example .env
php artisan key:generate
php artisan migrate:fresh --seed
php artisan serve
```

В Postman импортировать коллекцию и окружение `Homeostat.local.postman_environment.json`, затем проверить, что `base_url` указывает на `http://localhost:8000`. Токен не вставлять в файлы репозитория: коллекция сохраняет его только в переменную окружения/коллекции.

## Обязательные ручные проверки

- register/login для listener, artist и admin;
- 401 без токена и с просроченным/отозванным токеном;
- 403 для неправильной роли, чужого ресурса и blocked-пользователя;
- 404 для отсутствующего трека, жанра, playlist и вложенного ресурса;
- 409 для жанра с треками, повторной модерации и превышения лимита pending;
- 422 для пустых/некорректных тел, файла неподдерживаемого типа и отклонения без причины;
- happy path artist → upload → admin moderation → public catalog → stream;
- фильтр, поиск, безопасная сортировка, пагинация и статистика;
- logout и повторное обращение тем же токеном.
