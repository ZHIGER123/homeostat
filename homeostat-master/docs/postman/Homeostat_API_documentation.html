🎵 Homeostat API (КП6)

REST API платформы Homeostat, версия v1. Во всех запросах: Accept: application/json, адрес берётся из {{base_url}}.

Запуск: поднять приложение (php artisan migrate:fresh --seed && php artisan serve), импортировать коллекцию и окружение, выполнить папки по порядку (Collection Runner). Идентификаторы созданных записей сохраняются в переменные коллекции автоматически.

Пользователь передаётся в теле/URL временно: после ПР8 его заменит токен Sanctum (Authorization: Bearer {{token}}).

Сгенерировано: 17 ноября 2026  ·  Postman Collection ID: Bb0aB1F5dD6dDC6a9040AcA2
